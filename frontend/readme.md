# Frontend

Production-ready React starter structure for the WeatherApp frontend.

## Stack

- React
- Vite
- ESLint

## Structure

- `src/components` reusable UI pieces
- `src/pages` screen-level components
- `src/hooks` custom React hooks
- `src/services` API and integration modules
- `src/utils` helper utilities
- `src/constants` shared static config
- `src/styles` global styling layers

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
